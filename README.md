# ΝΟΠ — Νέο Website

Αρχικό responsive prototype για τον Ναυτικό Όμιλο Παμβώτιδος.

## Αρχεία
- `index.html` — η αρχική σελίδα
- `style.css` — design / responsive layout
- `script.js` — mobile menu και header
- `assets/logo.svg` — προσωρινό vector logo

## Επόμενα βήματα
1. Αντικατάσταση του προσωρινού logo με το επίσημο.
2. Προσθήκη πραγματικών φωτογραφιών του ΝΟΠ.
3. Μεταφορά των πραγματικών στοιχείων/σελίδων του παλιού site.
4. Δημιουργία ξεχωριστών σελίδων για Νέα, Canoe Kayak, SUP, Εγγραφές και Όμιλο.
5. Έλεγχος σε κινητό/tablet/desktop.
6. Ανέβασμα σε δωρεάν hosting και σύνδεση του nop.com.gr.
